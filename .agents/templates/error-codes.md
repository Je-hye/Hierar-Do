# Error Codes

<!-- 프로젝트 에러 코드 목록. 에이전트가 에러 처리 코드 작성 시 참조합니다. -->

## 형식

`E{카테고리}{번호}` — 예: `E1001`

## 카테고리

| 접두사 | 영역 |
|--------|------|
| 1xxx | 인증/인가 |
| 2xxx | 입력 유효성 |
| 3xxx | 비즈니스 로직 |
| 4xxx | 외부 서비스 |
| 5xxx | 시스템/인프라 |

## 에러 코드 목록

<!-- 코드 추가 시 여기에 등록하세요 -->

| 코드 | 메시지 | HTTP 상태 | 설명 |
|------|--------|-----------|------|
| E1001 | Unauthorized | 401 | 인증 토큰 없음 또는 만료 |
| E1002 | Forbidden | 403 | 권한 없음 |
| E2001 | Invalid input | 400 | 요청 바디 유효성 실패 |
| E3001 | <!-- 추가 --> | <!-- --> | <!-- --> |

## 에러 처리 규칙

- 에러 응답 형식: `{ "code": "E1001", "message": "...", "detail": "..." }`
- 5xx 에러는 상세 내용을 클라이언트에 노출하지 않는다
- 새 에러 추가 시 이 파일에 먼저 등록 후 구현
